# จัดรูปเอียง

เว็บ static ล้วน ประมวลผลในเบราว์เซอร์ ไม่มี server และ database

## Deploy บน Netlify
1. push โฟลเดอร์นี้ขึ้น GitHub
2. Netlify > Add new site > Import an existing project
3. Build command เว้นว่าง, Publish directory = `public` (ตั้งไว้ใน netlify.toml แล้ว)

ทดสอบในเครื่อง: `npx serve public`

## ที่มีในเวอร์ชันนี้
- นำเข้ารูปได้ 2 แบบ: ลากวาง/ค้นหาไฟล์ หรือถ่ายรูปจากกล้อง (สลับกล้องหน้า/หลังได้ ถ้าเปิดกล้องในเว็บไม่ได้ จะมีทางเลือกใช้แอปกล้องของเครื่อง) กล้องต้องเปิดผ่าน HTTPS หรือ localhost
- ตรวจมุมเอียงอัตโนมัติ (เขียนเอง ไม่ใช้ไลบรารี) พร้อมสไลเดอร์ปรับมือ และครอปมุมดำออกให้
- เลือกความละเอียด ขนาดเดิม / HD / 2K / 4K / กำหนดเอง พร้อมแสดงขนาดผลลัพธ์
- แถบความคืบหน้าและเวลาที่เหลือขณะประมวลผล
- บันทึก JPG/PNG/WebP เลือกที่เก็บได้ใน Chrome/Edge (เบราว์เซอร์อื่นใช้ดาวน์โหลดปกติ)
- Popup พิมพ์ เลือกกระดาษ การวางรูป ขอบ แล้วเปิดหน้าต่างพิมพ์ของระบบ ซึ่งเลือกเครื่องพิมพ์ได้
- ล้างรูปออกจากแอปหลังบันทึก (เว็บลบไฟล์ต้นฉบับในเครื่องไม่ได้)
- ไอคอน SVG ไม่ใช้อีโมจิ และแจ้งเตือนผ่าน popup ทั้งหมด

## ขั้นปรับกรอบ (หลังถ่ายรูป)
- ถ่ายรูปเสร็จจะมีกรอบ 4 มุมครอบรูปให้อัตโนมัติ (แยกรูปออกจากพื้นหลังด้วย Otsu แล้วหาจุดมุมสุด ไม่ใช้ไลบรารี) ถ้าตรวจไม่ได้จะใช้กรอบเต็มภาพเว้นขอบเล็กน้อย
- ลากจุดมุมปรับได้ทั้งเมาส์และนิ้ว ขณะลากมีแว่นขยาย 4 เท่าจากภาพความละเอียดจริง แสดงเส้นกรอบทับขอบรูป และมีเส้นประแบ่งสามส่วนในกรอบไว้เช็กความตรง
- กด "ต่อไป" จะดึงภาพให้เป็นสี่เหลี่ยมตรง (perspective) แล้วเข้าหน้าเมนูเดิม ปุ่ม "ปรับกรอบรูปใหม่" ในแผงด้านขวากลับมาแก้กรอบจากรูปต้นฉบับได้
- รูปที่เลือกจากไฟล์เข้าหน้าเมนูทันทีเหมือนเดิม แต่กด "ปรับกรอบรูปใหม่" ได้

## ปรับคุณภาพด้วย AI
- ใช้ ESRGAN-slim (MIT) ขนาดราว 1 MB ต่อโมเดล รันบน TensorFlow.js + WebGL แบ่งเป็นชิ้นเล็ก ใช้แรมน้อย
- ผู้ใช้เลือกวิธีปรับคุณภาพเองที่แผงด้านข้าง: ปกติ (ไลบรารีของเบราว์เซอร์) หรือ AI ในเครื่อง ระบบจะบอกใต้ตัวเลือกว่า AI จะทำงานหรือไม่ ถ้าไม่ต้องขยาย รูปใหญ่เกิน หรือเครื่องไม่รองรับ จะใช้แบบปกติแทนอัตโนมัติ
- ไลบรารีและโมเดลโหลดครั้งแรกครั้งเดียว แล้วเก็บในแคชของเบราว์เซอร์ (ตั้ง cache ใน netlify.toml)
- ถ้าไม่พบไลบรารีหรือโมเดลในเว็บ (เช่นลบโฟลเดอร์ `public/models` ออกเพื่อลดขนาด repo) จะดาวน์โหลดอัตโนมัติจาก jsDelivr แล้วแสดงสถานะใน popup
- รูปต้นฉบับเกิน 4 ล้านพิกเซลจะไม่เสนอ AI เพราะช้าเกินไป และรูปที่ใหญ่กว่าความละเอียดเป้าหมายไม่ต้องใช้ AI

- ลำดับการรัน: WebGL (การ์ดจอ) > WASM > CPU ธรรมดา เครื่องที่ WebGL ใช้ไม่ได้จะใช้ WASM อัตโนมัติ

## ลดภาพแตกตอนปรับคุณภาพ
- ลดสัญญาณรบกวนแบบรักษาขอบ (ปิด/เบา/กลาง/สูง) ก่อนขยายรูป ช่วยรูปจากเว็บแคมที่มืดและเป็นเม็ดหรือบล็อก JPEG
- คุณภาพของ AI ปรับได้ 0–100% โดยผสมผลลัพธ์ AI กับการขยายแบบนุ่ม ลดพื้นที่สีที่ AI แต่งขึ้นเอง
- ลดค่าเพิ่มความคมหลังขยาย เพราะขยายสัญญาณรบกวนและขอบบล็อก
- ถ่ายรูปใช้ภาพนิ่งจากกล้องโดยตรง (ImageCapture) เมื่อเบราว์เซอร์รองรับ ได้ความละเอียดและความคมกว่าจับเฟรมจากวิดีโอ

## ลดอาการค้าง
- โหลดไลบรารี โหลดโมเดล และรัน AI ใน Web Worker (`js/ai.worker.js`) หน้าเว็บจึงไม่ค้างระหว่างโหลดและประมวลผล มีวอร์มอัปโมเดลหนึ่งครั้งตอนโหลดเพื่อไม่ให้ติดตอนเริ่มงานจริง
- ถ้าเบราว์เซอร์ไม่รองรับ Worker/OffscreenCanvas หรือ worker ใช้ไม่ได้ จะถอยไปรันในหน้าหลักแบบแบ่งชิ้นเหมือนเดิมอัตโนมัติ

## รองรับหลายอุปกรณ์และขนาดหน้าจอ
- เลย์เอาต์ยืดหยุ่น: จอกว้างแผงตั้งค่าอยู่ด้านข้างและเลื่อนตาม จอแคบแผงย้ายลงล่าง แถบปุ่มบันทึก/พิมพ์/ล้างรูปติดขอบล่าง ขนาดตัวอักษรปรับตามความกว้างจอ
- ภาพตัวอย่างและหน้าปรับกรอบคำนวณขนาดใหม่เมื่อหมุนจอหรือย่อขยายหน้าต่าง ใช้ความละเอียดตามจอ (devicePixelRatio) และหน่วย dvh รองรับแถบเบราว์เซอร์บนมือถือ
- จอสัมผัส: ปุ่มสูงอย่างน้อย 44 px จุดมุมกรอบจับง่ายขึ้น แว่นขยายเลื่อนให้พ้นนิ้ว popup เป็นแผ่นเลื่อนขึ้นจากด้านล่างบนจอเล็ก รองรับรอยบากและขอบจอ (safe area)
- มือถือมีเพดานขนาดรูปและขนาดที่ใช้ AI ต่ำกว่าเดสก์ท็อป เพื่อกันแรมไม่พอ และมีปุ่มแชร์/บันทึกลงอัลบั้มผ่านเมนูของระบบ
- เบราว์เซอร์รุ่นเก่าที่เปิดรูปด้วย createImageBitmap ไม่ได้ จะใช้วิธีสำรอง และถ้าเบราว์เซอร์เข้ารหัส WebP ไม่ได้จะเปลี่ยนนามสกุลไฟล์ให้ตรงกับรูปแบบที่ได้จริง

## เพิ่มคุณภาพภาพจากกล้องคุณภาพต่ำ
- **ปรับแสง สี คอนทราสต์อัตโนมัติ** (ปิด/เบา/กลาง/แรง): ปรับระดับสีขาว-ดำต่อช่องสี ถ่วงสมดุลสีขาว ดึงรูปมืดให้สว่าง เพิ่มคอนทราสต์และความสดใส เห็นผลในพรีวิวสด ใช้ LUT จึงเร็ว
- ตัดขั้นตอนเพิ่มความคมออกแล้ว
- กล้องหน้าเป็นค่าเริ่มต้น เลือกกล้องหลังได้ในหน้าถ่ายรูป
- ตอนเปิดกล้อง ขอให้กล้องโฟกัส ปรับแสง และสมดุลสีขาวแบบต่อเนื่อง ถ้าอุปกรณ์รองรับ
- ขีดจำกัด: ซอฟต์แวร์ลดสัญญาณรบกวนและช่วยเรื่องแสงสีได้ แต่เติมรายละเอียดจริงที่เซนเซอร์ไม่เคยเก็บไว้ไม่ได้ ถ้าต้องการคมสุด ให้ถ่ายในที่สว่าง

## ยังไม่มี
- ตรวจมุมเอียงอัตโนมัติ ตรวจกรอบ ดึงภาพให้ตรง และปรับความคมยังทำในหน้าหลักแบบแบ่งช่วง (ยังไม่ย้ายเข้า Worker)

## หมายเหตุเรื่อง CSP
- `netlify.toml` ตั้ง `script-src 'self' https://cdn.jsdelivr.net 'wasm-unsafe-eval'` โดยไม่เปิด `unsafe-eval` ไลบรารี tf.min.js มีโค้ดสำรองที่ใช้ `Function(...)` จึงประกาศ `regeneratorRuntime` ไว้ก่อนใน `js/ai.js` และ `js/ai.worker.js` เพื่อไม่ให้โค้ดส่วนนั้นถูกเรียก ห้ามใส่ข้อความ CSP ลงในแท็ก `<script src>`
